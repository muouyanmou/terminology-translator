# 🌐 多语言术语翻译器

一键输入术语，批量翻译成 11 种语言，直接导出 Excel。**无需本地安装 Python，点开链接即用。**

## 功能
- ✅ 支持 11 种语言
- ✅ 精准翻译（Google Translate 免费 API）
- ✅ 批量翻译
- ✅ 一键导出 Excel
- ✅ 完全免费云端托管

## 快速开始

### 1️⃣ 上传到 GitHub
1. 登录 GitHub 账号

## 使用步骤

**步骤 0** — 选择源语言（英文或中文？）
**步骤 1** — 输入术语（每行一个）
**步骤 2** — 勾选目标语言
**步骤 3** — 点翻译 → 下载 Excel

### 重要提示 ⚠️

**必须正确选择源语言！**
- 如果输入的是**英文术语**（如 circuit breaker），请选择 **英文**
- 如果输入的是**中文术语**（如 断路器），请选择 **中文（简体）**

## 使用示例

### 例子 1：英文 → 中文、日文

**输入**
```
circuit breaker
fuse
relay
```

**选择**
- 源语言：**英文** ✅
- 目标语言：中文（简体）、日文

**结果**
```
术语           │ 中文  │ 日文
────────────────┼───────┼─────
circuit breaker │ 断路器│ 遮断器
fuse            │ 保险丝│ ヒューズ
relay           │ 继电器│ リレー
```

### 例子 2：中文 → 英文、日文

**输入**
```
断路器
保险丝
继电器
```

**选择**
- 源语言：**中文（简体）** ✅
- 目标语言：英文、日文

**结果**
```
术语    │ 英文           │ 日文
────────┼────────────────┼─────
断路器  │ circuit breaker│ 遮断器
保险丝  │ fuse           │ ヒューズ
继电器  │ relay          │ リレー
```

## 常见问题

**Q: 翻译出来都是原文本？**
A: 可能源语言选错了。请检查"步骤 0"的源语言选择是否与输入术语的语言一致。

**Q: 翻译很慢？**
A: 这是正常的，免费 API 有访问限制。如果需要更快速度，可以升级为付费 API。

**Q: 需要付费吗？**
A: App 完全免费。翻译基于 Google Translate 免费 API。
